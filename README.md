# application-module

Automated end-to-end Playwright tests generated by the **STLC Automation Suite**.

## Getting started

```bash
npm install
npx playwright install
```

## Running tests

```bash
# Run all tests (headless)
npm test

# Run with browser visible
npm run test:headed

# Show HTML report
npm run test:report
```

## Structure

```
tests/
└── e2e/          ← generated Playwright .spec.ts files
playwright.config.ts
package.json
tsconfig.json
```
